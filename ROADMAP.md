# Roadmap

## Genesis 0.0.1-alpha, Bootstrap
Project foundation, documentation, package boundaries, desktop shell, and CI.

## Genesis 0.0.2-alpha, Parser
Reverse engineer the MS-3 TSL format, parse known fields, preserve unknown data, and add real fixtures.

## Genesis 0.0.3-alpha, Explorer
Library browser, patch search, and patch inspector.

## Genesis 0.1.0, First usable release
MS-3 editing, reliable round-trip serialization, and initial setlist workflow.

## Future
Nano Cortex, additional hardware plugins, show mode, and community fixture library.
