# SideStage Vision

SideStage exists to remove friction between musicians and live performance.

It should help musicians prepare faster, make fewer mistakes, spend less time programming gear, and spend more time playing music.

SideStage is broader than a hardware editor. Hardware integrations are plugins. The core product owns the musician-facing workflow and domain model.

Focus areas:
- Rig management
- Device configuration
- MIDI
- Patches
- Setlists
- Show preparation
